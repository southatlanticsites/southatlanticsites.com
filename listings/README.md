# Listing pages (made by the SAS Listing Tool)

Each folder here is one listing's web page, published from the SAS Listing Tool.

- Page address: https://www.southatlanticsites.com/listings/<slug>/
- Every published listing: https://www.southatlanticsites.com/listings/index.json
- The <slug> never changes once a listing is published, so links stay good when the
  price, photos or status change.
- `index.json` lists every published listing: slug, url, title, address, offering,
  status (Available / Under Contract / Leased / Sold), type, price, size, main photo,
  flyer and last update. Point the homepage cards and map pins at `url`, or read this
  file to do it automatically.
- Please don't edit files in these folders by hand: the next publish from the tool
  replaces them. Change things in the Listing Tool instead.
- Deal room documents are NOT stored here (this repository is public). They live in the
  secure Cloudflare deal room and are only shown to registered visitors.
